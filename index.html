Got API Documentation

Unified API Gateway — one endpoint to access hundreds of AI models. Fully compatible with the OpenAI API format.

Quick Start

Got API exposes a fully OpenAI-compatible API. Use any OpenAI SDK with your custom base URL and API key.

1. API Endpoint

https://gotapi.ai/v1

2. Chat Completion (cURL)

curl https://gotapi.ai/v1/chat/completions \
  -H "Authorization: Bearer ***" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

3. Python (OpenAI SDK)

from openai import OpenAI
client = OpenAI(base_url="https://gotapi.ai/v1", api_key="***")
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)

4. Node.js (OpenAI SDK)

import OpenAI from 'openai';
const client = new OpenAI({ baseURL: 'https://gotapi.ai/v1', apiKey: '***' });
const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }]
});
console.log(response.choices[0].message.content);

Sign Up & Login

Got API supports multiple ways to create and access your account:

  • Email & Password — Register with your email address
  • GitHub OAuth — Sign in with your GitHub account
  • Discord OAuth — Sign in with your Discord account

Get API Key

After logging in, go to API Keys and click "Create Token". Name it, set restrictions (optional), and copy the token immediately.

Using the API

Compatible with OpenAI, Claude, Gemini formats. Supported endpoints:

  • POST /v1/chat/completions — Chat completions
  • GET /v1/models — List models
