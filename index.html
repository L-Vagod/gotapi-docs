Got API 文档

统一 API 网关，服务于海量 AI 模型。通过标准 OpenAI 兼容接口，一个地址访问数十种模型。

快速入门

Got API 提供与 OpenAI API 完全兼容的接口，您可以使用标准的 curl、Python、JavaScript 等工具直接调用。

1. 获取 API 地址

登录后，在控制台首页即可看到您的专属 API 地址：

https://gotapi.ai/v1

2. 调用 Chat Completions

curl https://gotapi.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

3. Python 调用示例

from openai import OpenAI

client = OpenAI(
    base_url="https://gotapi.ai/v1",
    api_key="sk-你的令牌"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)

注册与登录

Got API 支持多种注册和登录方式：

  • 邮箱注册 — 使用邮箱地址创建账号
  • GitHub OAuth — 使用 GitHub 账号快速登录
  • Discord OAuth — 使用 Discord 账号快速登录

获取 API Key

登录 Got API 后，进入控制台 → API Keys 页面：

  1. 点击「创建令牌」
  2. 设置令牌名称（如 "开发环境"）
  3. 配置权限：可选择允许访问的模型范围
  4. 设置配额限制（可选）
  5. IP 白名单（可选，提升安全性）
  6. 创建后立即复制令牌值（关闭后不再显示）

使用 API

支持的接口端点

Got API 兼容 OpenAI 标准接口，同时支持 Claude、Gemini 等多种格式：

  • POST /v1/chat/completions — 聊天补全
  • POST /v1/images/generations — 图像生成（若渠道支持）
  • GET /v1/models — 获取可用模型列表

模型名称映射

使用模型广场展示的模型名称。支持多种大模型的统一接口调用，无需切换 API 地址。

令牌管理

令牌是 API 调用的身份凭证，每个令牌可以独立配置：

  • 配额限制 — 限制该令牌的最大使用额度
  • 模型限制 — 仅允许访问指定的模型
  • IP 白名单 — 限制只有特定 IP 可使用该令牌
  • 自动过期 — 设置令牌有效期

模型与定价

前往「模型广场」查看完整的模型列表和实时定价。Got API 支持 100+ 模型的计费路由，覆盖主流 AI 服务商。

模型按 Token 计费，支持分组差异化定价。不同的用户分组可配置不同的费率倍率。

安全与合规

Got API 基于 New API 平台构建，提供多层次安全防护：

  • HTTPS 加密 — 所有 API 通信通过 Cloudflare 全球网络加密传输
  • API Key 认证 — 每个请求需携带有效令牌
  • 令牌权限控制 — 支持模型限制、配额限制、IP 白名单
  • 用户角色体系 — Root / Admin / User 三级权限管理
  • 双因素认证 (2FA) — 支持 TOTP 两步验证
  • OAuth 认证 — 支持 GitHub、Discord 第三方登录
  • 数据导出 — 用户可主动导出使用数据

常见问题 (FAQ)

Got API 的定价方式是怎样的？

Got API 按 Token 用量计费，各模型定价以「模型广场」页面实时展示为准。平台支持用户分组和倍率配置，管理员可针对不同用户组设置差异化费率。如您有企业定制需求，请联系 support@gotapi.ai。

我的 API 请求数据是否安全？

所有 API 通信均通过 HTTPS 加密传输。API 令牌支持设置 IP 白名单和模型访问限制，有效防止未授权使用。您可以在控制台随时管理和撤销令牌。

支持哪些 AI 模型？

Got API 聚合了数十家 AI 服务商的 100+ 模型，包括 OpenAI、Anthropic (Claude)、Google (Gemini)、Meta (Llama) 以及多款国产大模型。具体列表请查看「模型广场」。

数据会存储在哪些区域？

Got API 总部位于香港，服务器部署在海外节点。API 请求经由我们的路由基础设施进行优化转发，不持久化存储您的对话内容。

SLA 服务等级是怎样的？

Got API 通过 Cloudflare 全球网络提供加速服务，内建多节点负载均衡和自动故障切换。具体 SLA 承诺请联系我们的销售团队了解企业方案。

如何使用兑换码充值？

登录后进入「钱包」页面，在兑换码输入框中输入您的兑换码即可。兑换码充值额度会实时到账。

如何将 Got API 接入到我的应用中？

只需将您的应用中的 API Base URL 改为 https://gotapi.ai/v1，API Key 改为您在 Got API 创建的令牌，即可使用 OpenAI 兼容 SDK 直接接入。

支持流式输出 (Stream) 吗？

支持。Got API 兼容 SSE (Server-Sent Events) 流式输出，只需在请求中添加 stream: true 参数即可。

我遇到了技术问题，如何获得帮助？

可通过邮件 support@gotapi.ai 联系我们。常见操作问题可在「使用日志」中查看调用详情，或参考本文档各章节指南。
