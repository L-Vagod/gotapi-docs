Got API Documentation

Unified API Gateway — one endpoint to access hundreds of AI models. Fully compatible with the OpenAI API format.

Quick Start

Got API exposes a fully OpenAI-compatible API. Use any OpenAI SDK with your custom base URL and API key.

1. API Endpoint

https://gotapi.ai/v1

2. Chat Completion (cURL)

curl https://gotapi.ai/v1/chat/completions \
  -H "Authorization: Bearer *** \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

3. Python (OpenAI SDK)

from openai import OpenAI
client = OpenAI(base_url="https://gotapi.ai/v1", api_key="***")
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)

4. Node.js (OpenAI SDK)

import OpenAI from 'openai';
const client = new OpenAI({ baseURL: 'https://gotapi.ai/v1', apiKey: '***' });
const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }]
});
console.log(response.choices[0].message.content);

Sign Up & Login

Got API supports multiple ways to create and access your account:

  • Email & Password — Register with your email address
  • GitHub OAuth — Sign in with your GitHub account
  • Discord OAuth — Sign in with your Discord account

Get API Key

After logging in, navigate to your dashboard and go to API Keys:

  1. Click "Create Token"
  2. Give it a name (e.g., "Development")
  3. Optionally restrict which models the token can access
  4. Set a usage quota limit (optional)
  5. Add IP whitelist for extra security (optional)
  6. Copy the token immediately — it will not be shown again

Using the API

Got API is compatible with the OpenAI standard. It also supports Claude, Gemini and other model formats:

  • POST /v1/chat/completions — Chat completions
  • GET /v1/models — List available models

Token Management

Each token is an independent credential with its own settings:

  • Quota limit — Cap total usage per token
  • Model restriction — Only allow access to specified models
  • IP whitelist — Restrict usage to trusted IPs
  • Auto-expiry — Set a validity period

FAQ

How is pricing calculated?

Per-token based on each model's rate. Real-time prices on the Model Square page.

Is my data secure?

All traffic encrypted via HTTPS. Tokens support IP whitelisting and model-level restrictions.

Which AI models are supported?

100+ models: OpenAI, Anthropic (Claude), Google (Gemini), Meta (Llama), DeepSeek, and more.

Where is data stored?

Global data centers. We do not persistently store conversation content.

Does Got API support streaming?

Yes, SSE streaming is supported. Add "stream": true to requests.
