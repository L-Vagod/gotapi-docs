Quick Start

Got API is fully OpenAI‑compatible. Replace your base URL and go:

# Base URL
https://gotapi.ai/v1

# Chat completions
POST /v1/chat/completions
Content-Type: application/json
Authorization: Bearer YOUR_API_KEY

{
  "model": "gpt-4o",
  "messages": [{"role": "user", "content": "Hello!"}]
}

Open Dashboard

Sign Up & Login

Sign up with Email, GitHub OAuth, or Discord. Registration is free — receive trial credit instantly.

💡 Tip

GitHub OAuth is the fastest path. No email verification required.

Get API Key

After logging in: Dashboard → API Keys → Create Token. Fill in the token name and quota, then copy the generated sk-… key.

Never share your key

Support key rotation

令牌管理

每个 API Key 支持以下配置：

  • 配额限制 — 单 Key 消费上限
  • 模型限制 — 指定可用模型白名单
  • IP 白名单 — 仅允许受信 IP 调用
  • 过期时间 — 自动失效
