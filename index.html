Got API Documentation

Unified API Gateway — one endpoint to access hundreds of AI models. Fully compatible with the OpenAI API format.

Quick Start

Got API exposes a fully OpenAI-compatible API. Use any OpenAI SDK with your custom base URL and API key.

1. API Endpoint

Your base URL is:

https://gotapi.ai/v1

2. Chat Completion (cURL)

curl https://gotapi.ai/v1/chat/completions \
  -H "Authorization: Bearer sk-your-token" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

3. Python (OpenAI SDK)

from openai import OpenAI

client = OpenAI(
    base_url="https://gotapi.ai/v1",
    api_key="sk-your-token"
)

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response.choices[0].message.content)

4. Node.js (OpenAI SDK)

import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://gotapi.ai/v1',
  apiKey: 'sk-your-token'
});

const response = await client.chat.completions.create({
  model: 'gpt-4o',
  messages: [{ role: 'user', content: 'Hello!' }]
});
console.log(response.choices[0].message.content);

Sign Up & Login

Got API supports multiple ways to create and access your account:

  • Email & Password — Register with your email address
  • GitHub OAuth — Sign in with your GitHub account
  • Discord OAuth — Sign in with your Discord account

Get API Key

After logging in, navigate to your dashboard and go to API Keys:

  1. Click "Create Token"
  2. Give it a name (e.g., "Development")
  3. Optionally restrict which models the token can access
  4. Set a usage quota limit (optional)
  5. Add IP whitelist for extra security (optional)
  6. Copy the token immediately — it will not be shown again

Using the API

Supported Endpoints

Got API is compatible with the OpenAI standard. It also supports Claude, Gemini and other model formats:

  • POST /v1/chat/completions — Chat completions
  • POST /v1/images/generations — Image generation (when the upstream channel supports it)
  • GET /v1/models — List available models

Use the model name shown in the Model Square on the website. All models are accessed through one unified endpoint — no need to switch base URLs.

Token Management

Each token is an independent credential with its own settings:

  • Quota limit — Cap total usage per token
  • Model restriction — Only allow access to specified models
  • IP whitelist — Restrict usage to trusted IPs
  • Auto-expiry — Set a validity period

Security & Compliance

Got API is built on the New API platform and provides multiple layers of security:

  • HTTPS Encryption — All traffic encrypted via Cloudflare's global network
  • API Key Authentication — Every request requires a valid token
  • Token Access Control — Model restrictions, quota limits, IP whitelist
  • Role-Based Access — Root / Admin / User permission levels
  • Two-Factor Auth (2FA) — TOTP-based two-step verification
  • OAuth Single Sign-On — GitHub and Discord login
  • Data Export — Users can export their usage data

Frequently Asked Questions

How is pricing calculated?

Got API charges per-token based on each model's rate. Real-time pricing is shown on the Model Square page. Custom pricing tiers are available for enterprise customers. Contact support@gotapi.ai for details.

Is my data secure?

All API traffic is encrypted via HTTPS. Tokens support IP whitelisting and model-level access control. You can manage and revoke tokens at any time from your dashboard.

Which AI models are supported?

Got API aggregates 100+ models from dozens of providers including OpenAI, Anthropic (Claude), Google (Gemini), Meta (Llama), DeepSeek, and many more. See the Model Square for the full list.

Where is data stored?

Got API is headquartered in Hong Kong. Our servers are deployed in global data centers. We do not persistently store your conversation content — requests are routed and forwarded in real time.

What SLA do you offer?

We use Cloudflare's global network for acceleration, with multi-node load balancing and automatic failover. Contact our sales team for enterprise SLA details.

How do I use a redemption code?

Log in, go to the Wallet page, and enter your code in the redemption field. Credits are applied instantly.

How do I integrate Got API into my app?

Simply set your API base URL to https://gotapi.ai/v1 and use your Got API token as the API key. Any OpenAI-compatible SDK will work.

Does Got API support streaming?

Yes, SSE (Server-Sent Events) streaming is fully supported. Add "stream": true to your request body.

I need help — how do I get support?

Email us at support@gotapi.ai. For self-service, check the Usage Logs for detailed call information and refer to this documentation.
