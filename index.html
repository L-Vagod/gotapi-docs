Quick Start

Your API base URL: https://gotapi.ai/v1

curl https://gotapi.ai/v1/chat/completions \
  -H "Authorization: Bearer ***" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o","messages":[{"role":"user","content":"Hello!"}]}'
